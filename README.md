# 净启 JingQi

**每一次打开手机，都不再被广告绑架。**

面向长辈与家庭设置者的 Android 本地开屏辅助工具。包含可以编译安装的原生应用、独立演示实验室、核心决策测试及路演资料。当前为 **0.3.2 比赛验证版**，并非经过大规模应用兼容性验证的正式产品。

0.3.2 针对右上角圆环“跳过”：支持小尺寸、不可点击但可读的文字，在同时识别广告标记后复核位置并触摸；支持 AM广告 等标记和“跳 过”。本地 OCR 改用两张画面复核，圆环内容动画不会直接取消识别，窗口切换、用户交互和屏幕尺寸变化仍会取消。新增两个圆环演示场景。保留 0.3.1 的及时补扫、200 毫秒触摸兜底及误触返回。百度网盘的实际效果仍需真机复测。

**[下载安卓安装包与完整交付文件](https://github.com/jzy114514jlp/jingqi/releases/tag/v0.3.2)**。普通使用只需安装 `JingQi-0.3.2.apk`；演示实验室为可选附件。安装后阅读说明并开启“净启 · 开屏守护”无障碍服务。纯图片按钮需 Android 11+ 并在设置单独开启“本地 OCR 兜底”。同签名旧版可直接覆盖安装。此版本使用调试签名，实际第三方应用效果仍需设备验证。

本版移除“开发者平台”、平台地址和上传码，改用邮件反馈：用户在报告页点击“通过邮件发送报告”，邮件收件人预填为 **MOMO20170611@outlook.com**。支持多选报告和可选截图；最终由用户在自己的邮件应用中发送。[邮件反馈使用说明](docs/EMAIL.md)

## 先安装体验

编译产物放在 `deliverables/`：

1. 在安卓手机安装 `JingQi-debug.apk`（净启）。最低 Android 8.0；截图与 OCR 需要 Android 11 及以上。
2. 同时安装 `JingQi-Demo-debug.apk`（净启演示实验室）。它仅提供受控演示场景，真实守护不依赖它。
3. 打开净启 → 开始设置 → 阅读并同意辅助操作说明 → 在系统无障碍设置中开启 **净启 · 开屏守护**。
4. 回到净启，确认“守护已开启”。按需选择长辈模式、截图取证或本地 OCR。
5. 打开演示实验室，逐一体验十二个场景。净启的周报、取证页面通过“查看演示记录”查看这些事件。

详细步骤与排错见 [真机安装与演示](docs/INSTALL.md)。不要把演示记录当作第三方 App 的测试数据。

## 已实现

| 能力 | 当前行为 |
| --- | --- |
| 自动跳过 | 严格检查文字、位置、大小、可点击性和唯一性；只可通过同样安全的小容器点击。前 10 秒观察，事件最短扫描间隔 100 毫秒且保证补扫，静态页面前 2 秒按 150 毫秒、随后按 350 毫秒轮询。无障碍点击被拒绝立即检查触摸兜底；接受后 200 毫秒仍未消失则重新检查唯一顶层按钮，最多触摸一次；检测到其他点击或页面变化即停止兜底。这些是调度间隔，不是手机上的实际成功耗时 |
| 防自动跳转 | 首次识别广告后 6 秒内，跳往已知目标且不在白名单时，尝试一次返回。默认开启误触保护，已识别广告中的点击也可返回；普通页面点击、识别前点击仍放行。仅尝试过跳过但未确认控件消失时，仍保留返回保护。返回键未恢复源应用，且原目标仍在前台、未观察到新操作时，700 毫秒后尝试打开源应用一次（可能回到首页）；3.4 秒内确认原应用恢复才计数。可关闭误触保护以主动查看广告 |
| 图片跳过按钮 | 没有文字的按钮，若资源名含 skip / tiaoguo，或其 ID 已在本机学习过，且同样满足角落、尺寸、可点击、唯一的检查，才点击；画面上有可读“跳过”文字时优先按文字处理 |
| 圆环跳过文字 | 唯一的右上角小尺寸“跳过”文字，即使无点击动作，在同一页面同时识别明确广告标记、文字启用且窗口位于顶层时，重新采集并确认位置后触摸文字中心；不点击整个广告父层 |
| 规则自学习 | OCR 点掉图片跳过按钮后，记住其下方唯一的可点击控件 ID；0.8 秒后确认该控件已消失才保存，下次无需截图即可识别。只对同一应用生效，可在设置中清除 |
| OCR 兜底 | 内置 ML Kit 中文模型，默认关闭，无须运行时联网；两张独立画面均须有明确广告标记（如 AM广告、广告、Ad）和同位置唯一角落“跳过”。只允许轻微识别偏移；用户交互、窗口切换、尺寸变化或过期时取消。每次会话最多尝试 3 轮，每轮最多两张截图，图片仅在内存中处理 |
| 本地记录 | Room 数据库；事件与截图保留 30 天（服务常驻时每 6 小时检查清理），页面最多读取最近 1000 条 |
| 取证 | 可选私有截图、矩形标注副本、原始 PNG 的 SHA-256 完整性校验、ZIP 报告导出 |
| 邮件反馈 | 单条或多选报告，预填收件邮箱 MOMO20170611@outlook.com、正文和 ZIP 附件；截图逐条勾选，附件限 15 MB，用户在邮件应用中确认发送；本机记录保留 |
| 长辈模式 | 放大字号、主页面总开关、确认返回后的离线语音提示 |
| 周报 | 最近 7 个自然日的实际事件、预计节省时长、应用排行、本地分享 |
| 白名单 | 从已安装应用列表中选择，或手动输入包名；对白名单应用不操作 |
| 演示实验室 | 跳过、自动返回、普通页面跳转放行、取证、多候选拒绝、画布 OCR、容器内跳过文字、只认真实触摸、拒绝无障碍点击、误点广告后返回、圆环跳过文字、圆环图片跳过共十二种场景 |

## 构建

推荐用 Android Studio 打开此目录，选择 JDK 17，安装 Android SDK 35，然后等待 Gradle 同步。也可以在命令行中：

```powershell
.\gradlew.bat :core:test :app:testDebugUnitTest :app:assembleDebug :demo:assembleDebug :app:lintDebug :demo:lintDebug
```

版本固定为 Gradle 8.9、Android Gradle Plugin 8.7.3、Kotlin 1.9.25、Room 2.6.1、ML Kit 中文文字识别 16.0.1。构建机器首次下载依赖需要网络。净启不申请 `INTERNET` 或 `ACCESS_NETWORK_STATE` 权限；邮件发送交给用户选择的邮件应用，ML Kit 用量上报通道仍被移除。

本工作目录中另外准备了 `.tools/` 内的便携工具链。可运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

它执行核心测试、界面启动与报告测试、两份 APK 构建和两份 Android Lint，并把 APK 复制到 `deliverables/`。`.tools/` 和 Android SDK 不应提交到代码仓库。换电脑优先使用 Android Studio，不需要复制它们。

Windows 上也提供可选的 `scripts/prepare-build.py`（需要 Python 3.12+）。阅读 Android SDK 许可后，以 `python scripts/prepare-build.py --accept-sdk-license` 准备本目录中的工具链。首次测试会下载校验过的 Robolectric 运行时。

```text

```

## 设计中的重要取舍

- **不确定就不操作。** “关闭”、正文里的“跳过”等模糊词不作为点击目标；不盲点规则坐标，不自动连续返回。
- **区分广告与普通页面。** 误触保护默认开启，会撤回已识别开屏广告中的点击跳转，无法判断用户是否真的想看广告；需要时可关闭。普通页面点击、识别广告前的点击仍放行；白名单始终优先。
- **统计有边界。** “执行跳过”是系统接受点击或完成手势；“确认返回”是观测到源应用恢复。成功率要通过人工标注测试计算。节省时间仅根据读到的倒计时估算。
- **不把观察说成定论。** 按钮大小用 dp 近似，不能换算为可靠的物理毫米；无可读关闭按钮不等于没有按钮；报告不是违法认定。
- **权限由用户开启。** 默认关闭守护、截图与 OCR。数据留在本机；用户主动选择分享或邮件反馈时，才授权所选接收应用读取报告。邮件截图需逐条勾选，发信由邮件应用负责。没有远程家人账户或云同步。

## 尚需真机完成的验证

设备未连接时无法证明厂商后台保活、广告覆盖率和端到端效果。15 款 App × 每款 10 次的实际测量、3–5 位用户体验反馈和录屏应在路演前完成。不要使用方案里的“90%”目标值作为实测成绩。
