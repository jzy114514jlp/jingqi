# 净启 0.3.2

处理百度网盘及其他应用的右上角圆环“跳过”反馈。用户截图显示圆环文字与 AM广告，实际节点结构和广告 SDK 尚未通过真机读取；本版做通用兼容，不保存截图或固化图片坐标。

- 右上角唯一的小尺寸跳过文字，即使没有无障碍点击动作，在同时读取明确广告标记、文字启用、窗口位于顶层时，重新采集节点确认同位置后触摸文字中心。不点击整个广告父层。
- 识别 AM广告 等 SDK 标记及“跳 过”“跳\n过”；广告设置、关闭广告等普通文字不作为广告标记。禁用、多候选、遮挡、越界或尺寸不合适的目标仍不操作。
- 本地 OCR 改用两张独立画面，每张均须识别广告标记和唯一角落跳过文字，复核位置交叠后才触摸。圆环的内容动画不再使结果直接失效；用户交互、窗口切换、屏幕尺寸/密度变化、设置关闭、白名单与过期仍取消。最多尝试三轮，识别图片仅保留在内存。
- 演示实验室 0.3.0 新增场景 11 圆环跳过文字和 12 圆环图片跳过；场景 12 持续产生动画和内容事件。
- 保留既有误触返回和固定邮箱 MOMO20170611@outlook.com，报告仍由用户在邮件应用中确认发送。

下载并覆盖安装 `JingQi-0.3.2.apk`，无需卸载同签名旧版。打开净启确认守护正常；纯图片按钮在 Android 11+ 上单独开启设置中的“本地 OCR 兜底”，重新进入百度网盘测试。可先用新版演示实验室场景 11、12 分别验证文字与 OCR 路径；OCR 关闭时场景 12 应保持不动。
