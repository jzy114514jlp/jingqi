# 旧版开发者平台（已停用的历史说明）

**自净启 0.3.0 起，主应用已移除此功能。** 现使用 [邮件反馈](EMAIL.md)，收件邮箱为 **MOMO20170611@outlook.com**。下文仅记录旧版后台的使用方式，文中设置/上传入口已不再存在；`server/` 源码与历史数据保留，但新版应用不会再连接此后台。

用户在净启里**自己挑选**要上传的报告，开发者在网页后台查看，用来排查“为什么某个 App 没跳过”这类问题。所有记录仍然保存在手机本地，上传不会删除本机数据。

## 启动后台（电脑）

需要 Python 3.9 及以上，不用安装其他依赖。

```powershell
powershell -ExecutionPolicy Bypass -File server\start-server.ps1
```

窗口会显示：

- **后台口令**：用于浏览器登录后台；
- **上传码**：填到手机里，防止陌生人往平台乱发数据；
- **局域网地址**：例如 `http://192.168.1.5:8787`，填到手机里。

首次运行时，如果 Windows 防火墙询问，请允许 Python 访问**专用网络**，否则手机连不上。口令和上传码保存在 `server/data/config.json` 里，删掉这个文件后重新启动，就会生成新的。

电脑浏览器打开 `http://127.0.0.1:8787/` 登录后，可以按应用、包名、说明或机型搜索，也可以按类型或“真实/演示”筛选。报告详情页会显示完整报告文字、机型、系统和截图，也可以在这里删除报告。

## 手机上传

1. 让手机和电脑连同一个 WiFi。
2. 净启 → **设置** → **开发者平台** → 填写平台地址和上传码。
3. 进入净启 → **取证**，有两种上传方式：
   - 点“选择报告上传到开发者平台”，勾选多条报告后点“上传所选报告”；
   - 打开单条报告，点“上传到开发者平台”。
4. 在确认框里决定是否附带截图。默认不附带，需要按报告逐条勾选。
5. 上传成功的报告会标为“已上传”。失败的报告保持勾选状态，可以重试；失败原因会显示出来，比如上传码不正确、连接超时。

## 会上传什么

| 内容 | 是否上传 |
| --- | --- |
| 报告文字、事件类型、观察说明、时间 | 是 |
| 应用名称与包名、跳转目标 | 是 |
| 手机厂商、型号、Android 版本、净启版本 | 是 |
| 原始截图与标注副本 | 只在该报告被单独勾选“附带截图”时上传 |
| 未选中的报告、屏幕节点、OCR 图像 | 从不上传 |

## 隐私与安全边界

- App 申请了 `INTERNET` 权限，但只有用户确认上传时，`Uploader` 才会发起网络连接。ML Kit 自带的用量上报通道已从清单中移除（见 `AndroidManifest.xml`），自动测试会检查这一点。
- 为了支持局域网演示，App 允许 HTTP 明文传输，所以 Lint 会提示 `InsecureBaseConfiguration`。如果平台部署到公网，必须使用 `https://` 地址。
- 平台会核对上传码，同时检查报告编号格式、截图文件名、PNG 文件头和 SHA-256 校验值；后台网页必须登录才能访问，页面输出会做转义。
- 这是比赛演示用的轻量后台，没有账号体系，也没有审计日志。正式上线前还需要补上 HTTPS、按设备区分的密钥、数据保留期限和隐私政策。

## 测试

```powershell
python server\test_server.py
```

这个测试覆盖了：上传码错误被拒绝；校验值、文件名、编号无效被拒绝；未登录时无法查看；登录后可以查看列表、详情和截图；页面能防住脚本注入；删除报告时截图一并删除；同一报告重复上传会覆盖旧内容；口令错误被拒绝。
