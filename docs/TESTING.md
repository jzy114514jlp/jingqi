# 测试计划

## 自动检查

`core` 的 JUnit 用例验证保守决策：明确标签、角落尺寸、多候选拒绝、重复节点去重、超时、普通计时器、源会话不延长、主动点击、白名单、未知目标、总开关、一次返回、返回确认失败、启动器重置。

`app` 另有 Robolectric 启动测试：四个页面和长辈开关、最终权限清单与备份标志、真实 ZIP 导出内容。测试运行时固定为 Android 9，仍不能代替真机。

0.3.0 的邮件测试还验证固定收件人、正文、附件 URI 与读取授权参数、逐条截图选择、独立草稿文件、无邮件应用的回退、有邮件应用时的草稿选择器、15 MB 上限，以及移除旧平台配置时保留守护设置。验证不发送真实邮件。AndroidX FileProvider 使用 Android 的 `/` 路径规则，无法在 Windows Robolectric 下直接解析主机路径；该边界的测试使用明确的 content URI，真实 FileProvider 读取及邮件附件兼容性须在手机验证。

执行：`gradlew :core:test :app:testDebugUnitTest :app:lintDebug :demo:lintDebug :app:assembleDebug :demo:assembleDebug`。这些检查不能替代设备上的无障碍行为验证。

0.3.1 增加调度和服务回归：事件限流后的补扫、事件洪峰不推迟检测、无事件迟到按钮、会话取消、200ms 兜底、候选变多禁止触摸、误触返回及主动放行、返回键失败后只恢复一次原应用、无窗口事件时确认返回、用户操作/切换应用/关闭开关取消恢复。服务测试仅用 Robolectric 提供系统拥有的窗口快照，真实广告 SDK、系统返回栈和厂商限制仍需真机验证。

0.3.2 增加 SDK 广告标记、中文间隔、右上角小文字、禁用/遮挡/多候选拒绝、两帧 OCR 位置复核以及动画内容事件和真实交互区别的回归。OCR 测试使用人工构造的文字与框位置，不代表 ML Kit 已识别用户截图。

## 十二个受控场景

| 场景 | 应有行为 | 观测方式 |
| --- | --- | --- |
| 唯一角落跳过 | 执行一次点击 | 场景完成页 + 演示“执行跳过”事件 |
| 无点击跨应用跳转 | 自动返回一次 | 恢复源场景 + “确认返回”事件 |
| 普通页面主动跳转 | 不返回 | 目标页保持前台 |
| 8 秒、无节点关闭按钮 | 保存观察；截图依设置 | 查看报告、文件、标注副本 |
| 两个跳过按钮 | 不自动点击 | 等待至计时结束 |
| 画布按钮 | OCR 开启时尝试；关闭时不操作 | 完成页与 OCR 事件说明 |
| 容器内跳过文字 | 通过角落小容器点击一次 | 场景完成页 + 演示“执行跳过”事件 |
| 只认真实触摸 | 无障碍点击无效后，模拟触摸一次 | 场景完成页 + “改用模拟触摸”的跳过事件 |
| 拒绝无障碍点击 | 点击被拒绝后立即模拟触摸一次 | 场景完成页 + “系统拒绝了无障碍点击”的跳过事件 |
| 误点开屏广告 | 进入场景 1 秒后点击；开启误触保护时返回，关闭时放行 | 两种开关状态分别验证；只在识别广告后 6 秒内测试 |
| 圆环跳过文字 | 非可点击的小文字与 AM广告 同时存在时，复核后触摸文字中心 | 场景 11 完成页；OCR 关闭时也可测试 |
| 圆环图片跳过 | 内容动画持续更新，两次本地 OCR 确认同位置后才触摸 | Android 11+ 场景 12；分别验证 OCR 开/关、识别中手动触摸或离开时取消 |

另外复测总开关关闭、白名单、Android 10 无截图、Android 11+ 截图、横竖屏、权限撤销、进程重启、没有离线中文 TTS、没有分享接收器、30 天保留与清除记录。

邮件真机验收：安装并登录邮件应用，分别测试单条、多条、仅文字和带截图；检查收件人为 `MOMO20170611@outlook.com`，正文与 ZIP 一致，截图仅来自勾选记录。实际投递需人工发送后查看客户端与收件箱，自动测试不证明已经收到邮件。

## 15 款 App × 10 次

使用 [real-device-results.csv](real-device-results.csv) 记录逐次观察。CSV 是空表，不含伪造数据。先记录机型、系统、App 版本、净启版本；每次冷启动手动清理被测应用任务并观察是否真的展示广告。

- 分母只能包括有对应广告/跳转的有效测试；没有广告的启动不能算跳过成功。
- 跳过成功率 = 实际广告被自动关闭次数 / 有可跳过广告的有效启动次数。
- 误点率 = 点击了非广告目标的次数 / 净启全部自动点击次数。
- 返回成功率 = 实际恢复源应用的次数 / 应撤回的有效自动跳转次数。
- 误返回率 = 正常跳转被错误返回次数 / 正常跳转测试次数。
- 节省时长最好用同一场景有/无净启的屏幕录制测量；应用内倒计时估算不能代替测量。

路演需要同时披露样本数、机型和不支持的场景。只报百分比而不报分母会掩盖结果。

## 3–5 位用户体验

由用户本人同意后，在家人帮助下安装；明确说明读取屏幕与模拟操作。使用一天后询问：设置是否容易、提示是否打扰、是否发生正常操作被返回、能否找到关闭按钮。只收集自愿反馈，不预写“真实用户评价”。
