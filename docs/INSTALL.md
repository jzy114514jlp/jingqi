# 真机安装与 3 分钟演示

## 准备

- 一部 Android 8.0 及以上手机；推荐 Android 11+，以体验截图和 OCR。
- 把两份 APK 传到手机，通过系统安装器安装。它们使用调试签名，适合本次本地验证，正式发布应配置自己的签名。
- 如系统不允许开启侧载应用的无障碍，请在应用详情检查“允许受限设置”等入口；不同系统名称和策略不同。受管理设备可能不允许启用，请遵守设备管理设置。
- 在净启内阅读用途说明后开启系统无障碍服务。净启不能也不会自行开启这些权限。

## 演示顺序

1. 净启首页开启守护；展示本地处理与“报告由你选择发送”。
2. 打开演示实验室 → **01 自动跳过**。应看到跳过按钮被点击，并进入结束页面。返回场景列表。
3. **02 自动跳转后返回**。页面会在 1.8 秒后启动模拟购物页，净启应尝试返回。返回后会记录“确认返回”。该页面不要求摇晃手机，使用定时跳转稳定模拟广告拉起其他 App 的结果。
4. **03 正常点击放行**。点击购物页按钮，净启应保持不动；手动返回。
5. 净启设置 → 开启截图取证 → 返回实验室 → **04 截图与报告**，等待 8 秒。
6. 净启取证 → 打开“查看演示记录” → 页面观察 → 查看并导出报告。
7. 可选：点击“通过邮件发送报告”，确认收件邮箱 **MOMO20170611@outlook.com**，选择是否附截图后打开邮件应用；检查正文与 ZIP 后自行发送。详细步骤见 [邮件反馈](EMAIL.md)。
8. 可选：开启本地 OCR，再运行 **06 图片文字 OCR**。这会经过系统截图和本地识别，首轮可能比节点点击慢；不成功时不要将其讲作已支持所有图片广告。
9. **10 误点广告后返回**：进入后等约 1 秒，再点“模拟误点广告”。默认应返回；关闭设置里的“误触广告后返回”后重试，应停留在目标页。普通页面的场景 03 不受该开关影响。
10. **11 圆环跳过文字**：文字可读但没有点击动作，预期复核广告标记和唯一右上角目标后触摸；不需要开启 OCR。
11. **12 圆环图片跳过**：Android 11+ 上单独开启“本地 OCR 兜底”，再进入场景。圆环持续动画与内容更新，两张画面复核通过后才尝试；关闭 OCR 时应保持不动。

## 验证保护措施

- 在 **05 多候选不点击** 中，应保持不动直至场景结束。
- 添加 `cn.jingqi.demo` 到白名单，然后重试所有场景，均不应自动操作。
- 关闭首页总开关，再试场景，均不应自动操作。
- 查看周报时默认不含演示记录；开关切换后才显示演示事件。
- 禁用截图后应继续记录事件，但新报告不附图片。

## 常见问题

**无障碍显示开启，实际没有动作**：确认净启首页总开关开启、已同意说明、应用不在白名单。退出演示场景回到列表后重试；同一应用的中间页面不会不断重新计算 6 秒窗口。

**报告没有截图**：Android 11 以下不支持此截图 API；截图默认关闭；系统保护页面不可截取；页面切换过快也可能错过。文本记录可以独立存在。

**无中文语音**：当前设备必须有离线中文 TTS 语音。净启不会为语音联网下载模型，找不到合适语音时静默。

**某 App 不跳过**：未知布局、没有可读节点、多个候选、非角落按钮、受保护窗口都会保守放行。当前只内置经过演示验证的规则，并未承诺主流 App 全覆盖。取证页的“操作提示”会写明没点的原因，可以勾选后通过邮件反馈，方便排查。

**误点广告没有返回**：0.3.1 新增并默认开启“误触广告后返回”；请同时打开“防自动跳转”。只有先识别到开屏广告，且在之后 6 秒内跳往已知目标、双方均不在白名单时才处理。普通页面点击、未知目标和识别之前的点击不会强制返回。返回键无效时可能尝试打开原应用一次并进入首页；“操作提示”记录请求及失败原因，可和该应用的“页面观察”一起发送反馈。

**百度网盘跳过仍慢**：新版增加及时补扫，并将触摸兜底检查缩至 200 毫秒；这不代表所有广告都能在 200 毫秒内关闭。重新打开百度网盘出现开屏广告后，导出同一时段的“页面观察”“执行跳过”和“操作提示”，新版会包含识别时点及操作耗时。

**圆环“跳过”关不掉**：0.3.2 支持右上角不可点击的小文字并识别 AM广告。若整个按钮只存在于图片中，在 Android 11+ 的净启设置单独开启“本地 OCR 兜底”，重新进入目标应用后测试。OCR 必须两次读出广告标记和同位置跳过文字；文字对比度低、识别不出、窗口受保护或候选不唯一时不会盲点。第三方应用真实效果需在手机确认。

**如何更新已安装版本**：将新的 `JingQi-debug.apk` 传到手机并覆盖安装同签名旧版，保留设置和报告。更新后，“设置 → 报告反馈”应显示上述邮箱。无需卸载应用，也无需填写平台地址或上传码。

**后台一段时间停止**：部分厂商限制后台服务。由用户在系统应用管理中检查相关设置，重新确认无障碍服务状态；仍需针对具体手机测试。

## USB 安装（可选）

手机已开启 USB 调试且电脑已被授权时：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/install-device.ps1
```

脚本要求恰好连接一台已授权设备，不会自动授权调试或打开无障碍。
